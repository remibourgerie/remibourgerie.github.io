# Rémi Bourgerie — Personal Website

My personal academic website, built with React, TypeScript, Supabase, and Tailwind CSS.

Live at [remibourgerie.github.io](https://remibourgerie.github.io)

## Stack

React + Vite · TypeScript · Tailwind CSS · shadcn/ui · Supabase · Supabase Edge Functions

## Setup

```bash
npm install
cp .env.example .env  # fill in your Supabase URL and anon key
npm run dev
```

Built with the help of [Claude](https://claude.ai).
